# 教师名单导入说明（P7B）

教师名单是**批量开号与课表导入的前置条件**：没有教师档案，课表里的"教师"列无从匹配，
账号也无法绑定到本人。本文件说明怎么导入、编号怎么定、以及哪些情况会被整批拒绝。

---

## 1. 数据来源：真实名单只算"已导入未核实"

教师档案有一个不可绕过的属性 `data_origin`，取值只有三种：

| 取值 | 含义 | 谁能改成它 |
|---|---|---|
| `SIMULATED` | 虚构演示数据 | 种子脚本 |
| `IMPORTED_UNVERIFIED` | **真实名单，但未经校方核对** | 名单导入（本文件所述） |
| `OFFICIAL` | 校方正式确认 | 需书面依据，不由导入产生 |

导入真实名单得到的是 **`IMPORTED_UNVERIFIED`**，不是 `OFFICIAL`。
原因很直接：名单是某个人给的，不等于学校核对过。系统不得因为"数据是真的"
就认定"课表是官方的"——那是两件事。

`SIMULATED` 永远不能升级为 `OFFICIAL`（P3 已定的硬约束）。

---

## 2. 名单格式

两种都收：

**A. 带表头（CSV / XLSX 另存为 CSV）**

```
教师编号,姓名
JS001,虚构教师甲
JS002,虚构教师乙
```

- `姓名`：必需
- `教师编号`：可选。留空则由系统生成

**B. 无表头，每行一个姓名**

```
虚构教师甲
虚构教师乙
```

此时所有编号由系统生成。

（以上示例一律用虚构姓名。**真实名单不要写进仓库里的任何文件**，包括文档示例与测试数据。）

文件必须是 UTF-8。`.docx` / `.pdf` / 图片不受支持。

---

## 3. 教师编号：自带优先，留空则生成；生成的是占位

编号一旦落库，就会被课表和账号引用。因此规则是：

1. **校方有正式工号 → 填在"教师编号"列**。这是首选，一步到位。
2. **没有工号 → 留空**，系统按 `T###` 顺序生成（跳过库中已有的编号）。
   生成出来的编号会标记为 `generated`，并在审计里留下 `IDS_GENERATED_PENDING_OFFICIAL`。
3. **生成后不允许就地改写**。若校方后来给出正式工号，必须走一次显式迁移
   （改名 + 同步课表与账号引用 + 留审计），不能简单地 UPDATE 一个字段——
   那会同时断掉已建的课表与已开的账号。

第 3 条是本功能最容易被低估的风险：**先图省事生成，后面再改，代价远高于一开始就要到工号。**
所以在可能的情况下，请先向校方索取带工号的名单。

---

## 4. 整批拒绝：任何一行有问题，一个都不写

出现以下任一情况，整个文件被拒绝，教师档案一条都不会建立：

| 情况 | 原因 |
|---|---|
| 姓名为空 | 无法识别 |
| 名单内姓名重复 | 课表按"教师姓名或工号"匹配（docs/04 §1），重名会让后续课表导入"同名无法区分"而整批失败 |
| 与库中已有教师同名 | 拒绝覆盖式更新；确需改名请走显式变更 |
| 名单内编号重复 | 同一编号不能指两个人 |
| 编号与库中已有编号相撞 | 同上 |
| 编号格式不合规 | 1–32 位字母、数字、下划线或连字符，且以字母或数字开头 |

多个问题会**一次性全部列出**（含行号），方便直接改文件，而不是改一个跑一次。

---

## 5. 谁能导入

`IMPORT_ROSTER` 权限当前只授予 **S（课务管理人员）**。

管理员（A）**没有**这个权限——业务基础资料不由管理员代管（与 INV-08 同向：
管理员只管账号、权限、备份、部署）。执行人还必须已改掉初始口令。

---

## 6. 使用方法

```bash
CA_DB_PATH=<库路径> \
CA_ACTOR_LOGIN=<课务账号> \
CA_ACTOR_PASSWORD=<口令> \
CA_ROSTER_CSV=<名单文件> \
CA_OUT_FILE=<对照表输出路径> \
npm run import-teachers
```

四个必填环境变量缺一即退出（退出码 2），不猜默认值。

成功后打印编号/姓名对照表，并按要求写入 `CA_OUT_FILE`（权限 0600）。

---

## 7. 个人信息保护（重要）

教师名单属于个人信息，请注意：

- **不要把名单文件放进代码仓库**。仓库是公开的，一旦提交即永久留痕
  （git 历史里的文件即使后续删除也能被检出）。名单请放在仓库之外的目录。
- 数据库文件同理，不要提交。
- 审计里**不存姓名清单**，只记数量、来源文件名与文件指纹；
  名单本身已经存在教师表里，没必要再往审计里复制一份。
- 导出的对照表含姓名，分发后及时删除本地副本。

---

## 8. 已知缺口

- **只支持教师名单**，班级名单、科目名单尚未提供导入（课表导入同样需要它们）
- 无"改名"功能：教师改名需走显式变更，不能靠重新导入覆盖
- 无编号迁移工具：正式工号到位后的迁移目前只能人工做
