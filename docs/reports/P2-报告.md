- 结构性冲突检测：同教师 / 同班级同一时段重复排课

- 服务层：`build` / `teacherView` / `classView` / `explainDay`

**拒绝了**

| 诱惑 | 为什么不 |
|---|---|
| 首周默认按单周算 | `rotation.parityBase` 是 L1 空值必填项。学校没说哪周是单周，任何默认值都是开发方替学校定制度 |
| 调休日默认按"当天星期"上课 | 学校说"10 月 10 日上课"不等于说"上周四的课"。缺 `followsWeekday` 就整日 `UNKNOWN_CALENDAR` |
| 考试周由系统自动识别 | 哪些天停课是校方登记的事实，不是代码推断的结论 |
| 用开始/结束时间做时段重叠判断 | 结束时间缺失时无从判断。只用 `(date, period)` 判等，缺时间的课次不进硬冲突 |
| 轮换课按奇偶或实际次数推算 | BIZ-06 未定。只返回 `UNKNOWN_ROTATION`，课次表里一条都不生成 |

## 3. 关键设计取舍

### 3.1 单双周基准必须显式声明（对 P1 契约的一处细化）

P1 的 `Calendar` 类型注释写的是"第 0 周记为 ODD"。那是契约示例，不是学校确认的口径。P2 的 `Term.firstWeekParity` 为 `'ODD' | 'EVEN' | null`：

- 有值 → 按声明推算
- `null` → 该学期所有单双周课程进入 `UNKNOWN_PARITY`，不生成课次；`parity='ALL'` 的课程不受影响

这与 L1 `rotation.parityBase` 空值必填一致。P1 的参考引擎保留原样作为契约样本，不被 P2 引用。

### 3.2 课次表是派生数据，不是事实

`occurrence` 表可以由 `teaching_template + calendar_exception + bell` 完全重建，`build()` 每次先删后插（单事务）。因此：

- 它不是"已生效事实"，重建不违反 INV-14
- 任何业务写操作（P4 起的变更、P6 的应急）都不得直接写这张表
- 指纹测试证明：同一资料构建两次、或只重建单日，结果与全区间构建逐字节一致

### 3.3 无法判定时必须显式外露

`TimetableView.complete` 为 `false` 时，视图同时给出 `unresolved`（哪些模板哪一天、为什么）与 `unknownDays`（哪一天、为什么）。前端不得把"没有课次"直接渲染成"没课"——这是 INV-11 在查询侧的落点。

### 3.4 冲突分两级

| 级别 | 条件 | 处理 |
|---|---|---|
| `HARD` | 同 (日期, 节次) 两条以上，且全部 `certainty=KNOWN` | 事实矛盾，必须由排课人员修正 |
| `UNRESOLVED` | 同上，但至少一条时间不确定 | 只提示待核验，不下结论 |

### 4.4 测试抓到的三个真实缺陷（已修）

| 缺陷 | 后果 | 修法 |
|---|---|---|
| 非法日期 `2026-02-30` 被字符串比较判成"学期外" | 静默返回"没课"，不报错 | `resolveDay` 先 `parseDate` 校验再比较 |
| 课次 ID 内含 `|`，视图比对用 `|` 分隔 | 属性测试读错字段，校验形同虚设 | 比较行改用 `\u001f` |
| 冲突测试用例本身构造错误（同一对课次同时触发教师与班级两种冲突） | 断言值写错 | 修正用例 |

第二条值得单独说：它说明"看起来在比对"和"真的在比对"是两件事。如果没跑属性测试，这行代码会一直显示通过。

## 6. 引入的假设与风险

| 编号 | 内容 | 影响 | 处置 |
|---|---|---|---|
| P2-A1 | 周六周日默认不是上课日，只有登记为调休才上课 | 若学校存在常规周六上课，会漏排 | 已作为通用默认记录；真实校历接入时用例外覆盖，不改代码 |
| P2-A2 | 冲突判等用 `(日期, 节次)`，不做时段重叠 | 不同节次但时间重叠（如第 1 节拖堂）检测不到 | 属排课数据质量问题，P7 真实数据核验时评估 |
| R-13 | `node:sqlite` 在 Node 24 仍标 experimental | 若校方服务器是 Node 20，需换 `better-sqlite3` 或 PostgreSQL | T-02 必须确认服务器 Node 版本；存储层已隔离在 `src/store/database.ts`，替换不影响领域层 |
| R-14 | 单双周基准未声明时整学期单双周课程不可用 | 若学校不提供该口径，双周课会持续缺失 | 配置页显示 `NOT_CONFIGURED` 并阻断，不静默补默认值 |
| R-15 | 调休必须由校方说明"按哪天的课表" | 只给"当天上课"的通知无法落地 | 返回 `UNKNOWN_CALENDAR`，在导入报告中标为待补信息 |
